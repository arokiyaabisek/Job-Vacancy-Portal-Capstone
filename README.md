# Job Vacancy Registration Portal (Capstone)

A web portal in which a company logs in and registers a job vacancy. HTML, CSS, JavaScript, PHP and MySQL on XAMPP.

Files: `index.html` (login and form), `database.sql`, `db.php`, `submit_job.php`, reports (PDF).

## Run with XAMPP
1. Start Apache and MySQL.
2. Copy this folder to `C:\xampp\htdocs\job_vacancy_xampp`.
3. phpMyAdmin > SQL tab > paste `database.sql` > Go.
4. Open `http://localhost:8080/job_vacancy_xampp/index.html`.

The GitHub Pages link shows the front end only. PHP and MySQL run on XAMPP.
